# AI Builder — проверка бизнес-моделей

Прототип конвейера для поиска бизнес-моделей, проверки обязательных условий, независимого анализа рисков и сравнения перспектив первой оплаты за 90 дней.

## Текущий статус

**Проектирование: спецификации v0.2 готовы к ревью. Реализация ещё не начата.**

Работа ведётся через Spec-Driven Development: требования → спецификации → ревью → согласование → реализация → проверка критериев приёмки. Рабочие допущения явно отделены от подтверждённых требований.

## История работы

Первый коммит фиксирует фактический комплект документов на момент подключения Git. Предыдущие обсуждения не представлены как исторические коммиты. Дальнейшие изменения спецификаций и реализации фиксируются отдельными содержательными коммитами. Коммиты в публичном репозитории позволяют просматривать изменения каждого файла.

Исходное задание работодателя и локальный журнал обсуждения `full_tt.md` не входят в публичный репозиторий. Все необходимые для ревью проектные предложения описаны в `specs/`.

## Запуск

Исполняемого приложения пока нет. Инструкции запуска и результаты проверок будут добавлены после согласования спецификаций и реализации. Сайт планируется разместить на Aeza. Секреты, рабочие базы и приватные логи в репозиторий не публикуются.
