# 09. Интерфейс и сценарии

Статус: DRAFT v0.1. Язык русский. Публичный посетитель читает опубликованный результат; владелец управляет расчётами.

## Обзор прогона

Верх страницы: дата анализа, рынок, сценарий ресурсов и заметный статус «полный/частичный/демонстрационный replay». Далее счётчики без смешивания отказа и технической ошибки. Рейтинг по возрастанию score, с явной подписью направления. Отдельные вкладки/фильтры: рейтинг; нужна проверка; отклонено; не завершено. Фильтр не меняет рассчитанные места.

Строка модели: название, покупатель/оплата, score либо причина отсутствия, главный подтверждённый риск, компания-аналог, действие «Открыть» и checkbox «Сравнить». Нет фальшивого progress %: показывать «проверено N из 12», текущую стадию и статус worker.

## Карточка и источники

Порядок блоков задан в 07-ranking. Клик по утверждению раскрывает паспорт: метод, уверенность с основанием, даты, источник, фрагмент и результат проверки. Неразрешённый конфликт показывает обе версии рядом, последствия и вопрос человеку. Недоступная ссылка явно помечена; сохранённый фрагмент и дата доступа остаются. Источник открывается по HTTP(S) безопасной ссылке.

## Сравнение

До трёх моделей одного run/scenario. Синхронные строки: покупатель, выручка, общий балл, пять факторов, сроки первой оплаты, бюджет теста, три риска, ограничения. Одинаковые единицы; неизвестное — «нет данных». На мобильном — горизонтальная прокрутка с закреплёнными названиями строк либо последовательные карточки, без потери данных. Попытка добавить четвёртую предлагает убрать одну; разные run сравнивать в v1 нельзя.

## Действия владельца

- Создать live run после просмотра scenario/config и бюджетного лимита.
- Видеть прогресс/ошибку/стоимость, приостановить новые вызовы, возобновить.
- Открыть очередь ручных проверок, добавить основание и решение; видеть новую ревизию.
- Предпросмотреть и опубликовать ревизию. Новый частичный run не заменяет последнюю опубликованную версию сам.
- Скачать результат и очищенный аудит; опубликованные карточки не содержат owner credentials, секреты или приватные технические payload.

## Состояния интерфейса

Пустой проект: понятное описание, гостю «результаты ещё не опубликованы», владельцу создание прогона. Ноль прошедших: причины и исходные модели, без фиктивного победителя. Provider outage: готовые карточки доступны, причина и resume доступны владельцу. Неизвестный ID: 404. Загрузка не скрывает последний сохранённый результат. Ошибки читаемы, сохраняются после обновления страницы. Статусы различаются текстом, а не только цветом; управление клавиатурой и видимый focus обязательны.

## Пользовательская приёмка

На ширине 1440px три карточки сопоставимы по одинаковым строкам. Пользователь за две минуты сравнения трёх карточек может назвать сильнейшую по текущему рейтингу, объяснить два фактора различия и найти источник одного существенного утверждения. Это ручной usability-сценарий, не обещание, что каждый пользователь справится без проверки.
